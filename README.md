
# FocusBuddy 🎓

Agente de inteligencia artificial para estudiantes
universitarios, desarrollado con Python y OpenAI.

## Funciones

- Responder preguntas académicas.
- Organizar tareas por prioridad y fecha.
- Registrar tareas pendientes y completadas.
- Guardar información en un archivo JSON local.
- Ampliar el agente con herramientas académicas.

## Tecnologías

- Python
- OpenAI API
- JSON
- Git y GitHub

## Instalación

1. Clona el repositorio.
2. Crea un entorno virtual.
3. Instala las dependencias.
4. Configura la variable OPENAI_API_KEY.
5. Ejecuta el agente.

## Ejecución

python agente.py

## Seguridad

No publiques claves API ni datos personales.
Los archivos locales de tareas están excluidos de Git.
